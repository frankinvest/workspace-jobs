# Vercel Build Trigger (2026-06-04)

**用途**：作为 `vercel.json` 的 `ignoreCommand` 白名单命中文件。

**背景**：
- `src/pages/docs/[...id].astro` 路由渲染 `docs/` 下的所有文章
- 6.4 财经早餐 (`4c1500d`) 的原文也存放在 `docs/JJC-20260604-001-原文.md`
- 但 `vercel.json` 的 `ignoreCommand` 白名单漏了 `docs/`，导致 6.4 的 commit 被 Vercel 误判为"无前端变更"而跳过构建
- 本文件 + vercel.json 的 `docs/` 白名单修复打包在同一 commit 中，确保 Vercel 真正触发构建

**何时删除**：
- 如果未来通过更细粒度的 `vercel.json` 配置（如基于 `astro build` 输出检测）不再需要此占位文件
